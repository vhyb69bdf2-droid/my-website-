How it works

Two ways to read the clues

Easy Mode

Green confirms a digit and its position. Yellow means it exists but is misplaced. Gray eliminates it.

Group (3–5)

3 to 5 players race to crack one shared secret code that's randomly generated. Easy = everyone sees all guesses. Hard = only yours.
