How it works

Two ways to read the clues

Easy Mode

Green confirms a digit and its position. Yellow means the digit exists but is misplaced. Gray eliminates it from consideration.

5 3 8

Hard Mode

Yellow only means the digit exists somewhere. Position info is hidden and the digit tracker disappears entirely.

5 3 8

Custom Codes

Choose 3, 4, or 5 digits. Toggle repeat digits on or off. Every room can have its own rules.

Game modes

Pick how you want to play

🔗

Multiplayer

Create a private room and share the code with a friend. Both lock a secret number, then race to crack each other's code. Real-Time or Turn-Based.

👥

Group (3–5)

3 to 5 players race to crack a single shared secret code that's randomly generated. Easy = everyone sees all guesses. Hard = only yours.

🤖

vs Nova

Challenge CipherRoom's AI. Nova gets smarter at each level — Easy uses elimination, Medium tracks all clues, Impossible plays optimally.
