          How to Play

          Each player picks a secret number using the room's digit rule. On your turn, guess your opponent's number. After each guess you'll see:

          4
          Green = right digit, right position
          7
          Yellow = right digit, wrong position
          2
          Gray = digit not in the code

          First to guess the full code wins the round. In Real-Time mode, a 3-minute timer runs — if neither player guesses in time, choose Overtime or Draw.
